# Canvas Course Skills

Claude skills that read a Canvas course export (`.imscc`) and check whether the course
holds together: whether work is taught before it is due, whether every activity has a
Bloom's level, whether every rubric links to an assignment and every assignment to a
learning outcome, and whether every page meets accessibility standards.

The skills were built while redesigning GEOG 476 (GIS Practicum) in the Department of
Geography at Texas A&M University. Every check exists because a real defect reached a
real course. They are written to run on any Canvas course, not only that one.

## Status

This repository is in early development. The table below shows what is available and
what is planned, in the order it will be built. Every skill runs from the `.imscc` file
alone: anything Canvas does not export is inferred and reported with its evidence.

| Skill | What it does | Status |
|---|---|---|
| `reading-canvas-exports` | Turns a Canvas export into one `course_model.json` file that the other skills read, inferring meeting times, holidays and time zone from the export itself | Available in 0.1.0 |
| `checking-course-sequence` | Builds a graph of pages, assignments, lectures, activities and labs, and checks that nothing is due before it is taught, that syllabus dates match Canvas, and that every link works | Available in 0.1.0 |
| `tagging-bloom-levels` | Proposes a Bloom's level for every lecture, lab, activity and assignment, links each to the outcomes it measures, checks that each outcome climbs, and keeps a column for the instructor to confirm each level | Available in 0.2.0 |
| `aligning-rubrics-to-outcomes` | Checks every link from rubric to assignment to course outcome to program outcome, proposes the course-to-program crosswalk, drafts missing rubrics for review, and writes approved changes into a new copy of the export | Available in 0.3.0 (import into Canvas not yet verified) |
| `fixing-canvas-accessibility` | Scans every page for WCAG 2.1 AA problems (alt text, headings, link text, contrast, table headers, embed titles), writes a fix plan in which only alt text and link text need a person, applies it surgically, and repackages the course for import | Available in 0.4.0 (import into Canvas not yet verified) |
| `updating-course-dates` | Moves last term's course to a new term: maps every deadline, unlock date and written date onto the new term's class meetings, skipping holidays, and repackages the course for import | Planned |
| `reviewing-lecture-recordings` | Reads a lecture transcript and slide timeline, reports how the session went against its plan, what to improve, and examples given that no slide carries | Planned |

## Installing

These skills are packaged as a Claude Code plugin. In Claude Code, run:

```
/plugin marketplace add danielgoldbergtamu/tamu-geography-canvas-course-skills
/plugin install canvas-course-tools@tamu-geography-canvas-course-skills
```

To get a newer version later, run `/plugin marketplace update`.

## What you need

- A Canvas course export. In Canvas, go to **Settings**, then **Export Course Content**,
  choose **Course**, and download the `.imscc` file.
- Python 3.10 or later.

You do not need anything else. The skills read your meeting days, holidays and time zone from the export
and the syllabus inside it, and say what they assumed. If an assumption is wrong, the
skill tells you how to correct it.

## Your course data

The skills run on your own computer and read the export you give them. They do not
upload your course anywhere. A course export can contain names and email addresses in
announcements, discussions and page text, so keep exports and the files the skills
produce out of any public repository. This repository's `.gitignore` already does that
for its own folder.
